# Circles to the Max release preparation

The existing PictureDotPuzzle repository is the original source for Circles to the Max, Apple ID 1071902904. Its literal bundle identifier com.nathanfennel.circlestothemax was committed in January 2016 and still matches the live App Store record. Source master 4a1f70c5da55e4176fcbaa689ea87d2d53c305aa was clean and matched the remote before this work. The live version 1.0 was Ready for Distribution but historically removed for inactivity. This update is 1.1, build 4.

The SwiftUI home and settings screens wrap the original Objective-C photo-to-circle canvas. Photo selection, circle subdivision, shape slider, automatic reveal, reset and native image sharing remain. Settings persist appearance and real animation durations. Photo contents and canvas are temporary; Home warns before clearing the canvas. No account, server, analytics, advertisements or purchase system was added.

Build corrections recover the original NKFToolbar from the user's own repository at 56a66ab7c11afdf9d315331342191715c5327ff9 and vendor it into this repository. The original external sibling path could not compile. The existing privacy manifest and modern launch storyboard are now compiled resources. Xcode derives icon sizes from the original 1024 artwork; unused historical icon files remain under Release/LegacyIconSources. iOS 16 is the minimum for NavigationStack and the native photo picker.

Renderer fixes initialize color averages, correctly sample normalized source pixels and transparent colors, crop images without stretching, bound decoded working images to 1024 square pixels, correct quadtree counts/progress, forward canvas touch coordinates, avoid the canvas ownership cycle and keep UIKit export on the main queue. Pending automation work is invalidated when paused/reset/exited so an old canvas cannot keep changing the current model.

Run `bash scripts/check_render_core.sh` for four headless check groups against the actual C functions used by the UIKit renderer. These check real CoreGraphics pixel output and alpha, geometry for offset/odd dimensions, centered photo cropping, and complete quadtree counts/progress. No Simulator or native app window is launched. This is not a UIKit runtime or screenshot test.

Native verification remains necessary. Launch on iPhone and iPad, choose and cancel a photo, test a rotated portrait photo and large image, subdivide by touch/drag, adjust shape and animation settings, automate/pause/reset repeatedly, export an image through Share including Save Image, cancel the return-home warning, and confirm relaunch preserves settings while temporary artwork is cleared. Check landscape, iPad split view, text sizes, VoiceOver toolbar labels and Reduce Motion. Actual screenshots must be captured from this build.

Build 4 removes the eight legacy sample JPGs, whose authorship/redistribution evidence was not recorded, and uses one newly generated floral still-life image as the sole bundled example. This removes the unresolved rights dependency from the binary. The generated image and prompt are recorded in `Release/SAMPLE_IMAGE_PROVENANCE.md`. Original third-party code and notices remain, including Apple image-effects terms; the Icalia Labs helper includes its original MIT license in the bundled ThirdPartyNotices.txt, verified from [the author’s upstream source](https://github.com/Adrian2112/UIImage-BlurredFrame/blob/b2af8f1cd3aa62081dbc71802190597bd88f4c5d/LICENSE).

The release audit directory records the signed build 4 archive and independent native screenshots. Targeted iPhone and iPad UI tests passed for launch, Settings, the bundled sample canvas, touch subdivision, automatic reveal, Home confirmation and canvas reset. The iPhone and iPad screenshot assets are at `app-store-audit/2026-09-27-release/circles-to-the-max/native-qa-2026-09-29/`. Photo picker selection, image sharing, accessibility, and iPad multitasking still need final native checks; no App Store upload or submission is implied by the archive.
